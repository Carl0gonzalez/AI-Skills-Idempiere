Las ediciones MediaWiki utilizan el workflow de evidencia/sintaxis de idempiere-plugin-wiki-page, adaptado a una biblioteca de skills. Se omiten instalación OSGi, metadatos de bundle, release probada inventada y categoría Available Plugins. La petición bilingüe del usuario prevalece sobre el idioma inglés predeterminado de la skill.

Títulos propuestos: **AI Skills for iDempiere** y **Skills de IA para iDempiere**. Los enlaces Markdown funcionan dentro de este repo. Si se importan a una wiki GitHub separada, conservar o adaptar las rutas relativas al repositorio publicado; no asumir que se resuelven sin cambios.

Estado: **borradores versionados**. No se subieron ni previsualizaron en una wiki real. Las páginas tienen enlaces recíprocos; namespaces de idioma/categorías deben verificarse en el destino antes de publicar. Commit/push y publicación wiki son acciones separadas.
