# Shared skills

**English** | [Español](README.es.md)

Eleven workflows for architecture, quality, environments, task management and specialized components. Inspect the target release and supported APIs before using them.

| Skill | Purpose |
|---|---|
| [idempiere-architecture-patterns](idempiere-architecture-patterns/SKILL.md) | Choose the smallest compatible mechanism and distinguish core, plugin and environment. |
| [idempiere-plugin-quality-gate](idempiere-plugin-quality-gate/SKILL.md) | Coordinate test execution, coverage and honest quality evidence. |
| [crear-entornos-idempiere-envrc](crear-entornos-idempiere-envrc/SKILL.md) | Create and review isolated direnv environments with static checks. |
| [documentar-entornos-idempiere-envrc](documentar-entornos-idempiere-envrc/SKILL.md) | Document the operational contract of an actual .envrc. |
| [gestionar-tareas](gestionar-tareas/SKILL.md) | Maintain an existing task registry when explicitly requested. |
| [idempiere-event-annotation](idempiere-event-annotation/SKILL.md) | Implement focused annotated delegates using target-version APIs. |
| [idempiere-rest-resource](idempiere-rest-resource/SKILL.md) | Define REST contracts, access checks and ResourceExtension registration. |
| [idempiere-window-validator](idempiere-window-validator/SKILL.md) | Intercept window actions with complete callback paths. |
| [idempiere-zul-form](idempiere-zul-form/SKILL.md) | Build ZUL forms, controllers, wiring and packaged resources. |
| [idempiere-grouped-listbox](idempiere-grouped-listbox/SKILL.md) | Implement grouped list models, renderers and bounded data access. |
| [idempiere-wlistbox-custom-editor](idempiere-wlistbox-custom-editor/SKILL.md) | Customize existing WListbox column editors/display behavior. |
