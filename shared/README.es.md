# Skills comunes

**Español** | [English](README.md)

Once workflows para arquitectura, calidad, entornos, tareas y componentes especializados. Revisar la release objetivo y APIs disponibles antes de utilizarlos.

| [idempiere-rest-resource](idempiere-rest-resource/SKILL.md) | Definir contratos REST, controles de acceso y registro ResourceExtension. |
| [idempiere-window-validator](idempiere-window-validator/SKILL.md) | Interceptar acciones de ventana resolviendo todos los callbacks. |
